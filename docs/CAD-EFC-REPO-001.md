## Design finding

EFC has a strong public validation and publication surface, but public success,
source cleanliness, workflow activation, evidence projection and runtime
consumption are separate surfaces. They must not be collapsed into one green
status.

## Required parity tuple

```text
commit/tree
+ public artifact hash/version
+ workflow run receipt
+ DOI/provenance receipt
+ graph projection receipt
+ Cortex/world-model consumer receipt
+ rollback reference
```

## Key lanes

- CI/verify and AI council reliability;
- disabled workflow classification and reactivation;
- count/version parity across README, AGENTS, layer, llms and public pages;
- public ledger to graph evidence projection;
- apples-to-apples model comparison execution;
- likelihood/evaluation current-state aggregation;
- runtime consumer proof.

## Closeout

The CAD lane is not complete until each surface has an explicit receipt or an
owner/evidence/next-action blocker.
