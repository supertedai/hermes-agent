cross-domain meta-model and epistemic-operational framework**. It does not,
by itself, establish EFC as a validated universal ontology or cosmological
replacement.

## EFC axes

The Copilot interpretation identifies useful candidate axes, which this CAD
formalizes for testing:

1. **Ontology:** primitives, derived entities and regime-bound entities.
2. **Meta-epistemology:** how models, claims and evidence are compared.
3. **Field/topology:** gradients, relations, stability regions and transitions.
4. **Regime/scale:** L0–L3 or equivalent regime placement and validity.
5. **Dynamics:** flow, stabilization, corelock, EBE, transition and collapse.
6. **Cognition/AI:** agent, Cortex, latent-space and system organization.
7. **Measurement/validity:** regime-appropriate measurement and falsifiability.
8. **Operational control:** routing, attention, entropy, gaps, experiments and
   promotion.

## Recommended system role

Use EFC first as a **derived meta-layer**:

```text
world observation / claim
→ EFC coordinate proposal
→ entropy/uncertainty vector
→ model/regime/validity placement
→ gap and experiment prioritization
→ MWP/Cortex/agent routing
```

Atlas coordinates are read-model metadata, not truth scores or authority.

## Required separation

```text
EFC cosmological claims       = theory/evidence lane
EFC meta-model                = architecture/method lane
EFC ASI OS proposal           = runtime experiment lane
EFC atlas coordinates         = derived metadata lane
```

No layer may silently promote one of these into another.
