# ADR-CE-001 — Import cutting-edge patterns as gated experiments

**Status:** Proposed / evaluation required  
**Parent:** `MWP-UOSH-001`  
**Source register:** `mwp-cutting-edge-research-import-v1.json`

## Decision

External cutting-edge research is imported into MWP as a typed candidate:

```text
source
→ pattern
→ affected gap/CAD/ADR/BL
→ baseline
→ isolated shadow experiment
→ independent evaluation
→ owner promotion or discard
```

The import process must distinguish:

```text
source-backed observation
candidate design pattern
local experimental result
live production capability
```

## Accepted research directions

1. Collaborative/data-local harness evolution.
2. Longitudinal memory-on/off recursive-improvement evaluation.
3. Continual-learning transfer and interference metrics.
4. Budgeted world-model probing before high-risk actions.
5. Failure-amplifier subgraph repair.
6. Contextual experience replay.
7. Layered symbolic/statistical/LLM planning.

## Rejected shortcut

No paper, abstract, benchmark score or repository is allowed to directly change
MWP authority, install a skill, write the graph, alter scheduler policy or
promote a runtime route.
