# CAD-RI — Recursive Improvement and System-Intelligence Alignment

**Parent:** `MWP-UOSH-001`  
**Status:** `PROPOSED / EVIDENCE-GATED`  
**Purpose:** make recursive improvement a first-class architecture lane without allowing self-modification to become self-authority.

## Architecture

```text
web/research sources
  → source/provenance capture
  → hypothesis/pattern extraction
  → gap matching against MWP/CAD/ADR/BL
  → bounded proposal
  → isolated experiment
  → independent evaluation
  → owner/reviewer gate
  → promotion or discard
  → outcome/calibration
```

## Required planes

- **Discovery plane:** web search, papers, repositories, benchmarks and internal signals.
- **Epistemic plane:** source quality, provenance, uncertainty, contradiction and freshness.
- **Improvement plane:** proposal, baseline, experiment, evaluation, comparison and rollback.
- **Control plane:** MWP task, CAD/ADR/BL mapping, identity, scope, owner and lease.
- **Runtime plane:** actual model/provider/agent/skill/workflow deployment and readback.

## External recursive horizon gap

The system had strong internal coherence but lacked a continuously governed
external improvement horizon. This is a process/system gap, not a claim that the
owner was personally isolated. The scout must add:

```text
external horizon scanning
→ adversarial comparison
→ transfer analysis
→ baseline/evaluation
→ owner-gated promotion
```

External inspiration is not evidence. Internal architectural consistency must
be preserved while avoiding internal over-optimization.

## Capability boundary

The scout may discover and propose. It may not:

- alter its own system prompt or authority;
- install a skill without audit and owner approval;
- promote a model/provider/route;
- write graph, memory or Obsidian state;
- modify scheduler policy;
- claim success from executor output alone.

## Acceptance

A recursive improvement is accepted only with:

```text
source receipt
+ gap mapping
+ baseline
+ isolated experiment
+ independent evaluation
+ owner/reviewer decision
+ promotion receipt
+ rollback reference
+ post-promotion outcome
```
